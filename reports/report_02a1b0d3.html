📊 Approach & Query

Query Code


-- Query 3: Regional summary statistics
SELECT 
    region,
    ROUND(SUM(total_amount), 2) AS total_region_revenue,
    COUNT(DISTINCT fk_category) AS num_categories,
    COUNT(*) AS total_transactions,
    ROUND(AVG(total_amount), 2) AS avg_transaction_value,
    ROUND(MAX(total_amount), 2) AS max_transaction_value
FROM gold_product_category_sales_by_region
GROUP BY region
ORDER BY total_region_revenue DESC

Query Description

SQL queries aggregated total_amount by region and product category (fk_category), ranked categories within each region, and calculated summary statistics including transaction counts and average transaction values. Used window functions (ROW_NUMBER) to rank within partitions, enabling clear visibility of category performance tiers.
